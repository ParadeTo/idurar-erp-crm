## 风险提示

| 风险 | 影响 |
|---|---|
| 金额计算逻辑（链路 1-4）没有测试 | 修改计算公式或 paymentStatus 判定逻辑时，错误无法被自动发现 |
| JWT Session 逻辑（链路 5-6）没有测试 | 改认证流程极易引入安全漏洞 |
| Settings 门控（链路 7）没有测试 | API 字段改名或 Redux 结构调整会导致页面白屏，上线前无法感知 |
| 无测试框架配置 | 补测试需要从零引入依赖（推荐后端 Jest + supertest，前端 Vitest） |
